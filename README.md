# dotfiles

A collection of dot files

### Location

`.gitconfig` to be placed `~/.gitconfig`.

`.gitignore` to be placed in relevant repository root.

`.zshrc` to be placed `~/.zshrc`.

`jetbrains-settings.zip` to be consumed by a JetBrains product.

### Create symlink
```bash
ln -s /Users/larskristianhaga/dev/dotfiles/.gitconfig ~/.gitconfig
```

```bash
ln -s /Users/larskristianhaga/dev/dotfiles/.zshrc ~/.zshrc
```

### Verify symlink
```bash
ls -l ~/.gitconfig
```

```bash
ls -l ~/.zshrc
```
